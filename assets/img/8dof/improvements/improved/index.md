# improved

the largest reductions in leg count

Old version happened to be broken sometimes, with its unbreakable desire to stay on the line between start and end points. Also the inaccurate open-set's priority queue didn't help. It was producing some pathologically bad cases, like the first figure in the maze, I'm surprised we don't have win in all requests here. But the new version can produce more very short legs on sharp turns and on beginning of the route, we'll see it in the regressions category.

Fewer legs: 3528 out of 4663 requests used fewer legs, showing only 24 exemplary illustrations.
